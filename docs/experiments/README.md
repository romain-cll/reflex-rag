# Offline experiments

Throwaway scripts run during development to decide a design before coding it, with their outputs when they called a paid API. They are kept as records: the figures quoted in the spec revisions of `docs/features/` come from them. They were run from a scratch folder with absolute paths, against the dev corpus index (`.reflex/index.db`) and the traced runs named below; they are not part of the build and are not linted.
